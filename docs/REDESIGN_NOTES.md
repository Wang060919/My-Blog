# 个人网站改版维护说明

## 页面与内容

首页使用居中标题、缓慢流动的蓝色 SVG 波浪、手动切换的作品展示、一大两小作品卡、最近三篇文章与个人入口。内页沿用暖白、炭黑、低饱和蓝色及衬线展示标题。文章继续由原 bundles 和 slug 构建，没有改写历史文章。

项目正文位于 `content/projects/<slug>/index.md`。`lead` 为短介绍，`description` 为 SEO 和搜索摘要；`status`、`evidence`、`stack`、`visual`、`weight` 控制展示。`sourceURL`、`upstreamURL`、`relatedURL` 为空时不输出按钮。

- VanishTrans：依据 2026-10-17 查阅的公开仓库 README 与现有博客案例，公开地址为 https://github.com/Wang060919/VanishTrans 。
- ESP32 Lab：硬件学习方向，对应 https://github.com/78/xiaozhi-esp32 上游资料。未将上游实现或编译、烧录、设备测试列为个人已完成成果。
- ai-chat：本地 README 与代码结构仅能核实 Python 命令行输入和一次模型请求。没有确认公开仓库，不输出源码或演示按钮。

界面、开发板和终端均为 HTML/CSS 示意，并在页面标注。没有可公开的个人照片，关于区使用抽象插画，不使用生成照片冒充实拍。没有虚构邮箱、职业头衔、项目收益或用户量。

`content/docs/` 当前仅有 `_index.md`。正式入口显示“文档正在整理”，不发布示例教程；未来正文已有左侧文档树、正文与本页目录模板。手机文档导航和目录使用可折叠的原生元素。

## 交互和降级

`site.js` 使用原生 `<details>` 手机导航和 `<dialog>` 搜索。搜索可用 Ctrl/Cmd+K、方向键、Enter 和 Esc；关闭后恢复焦点。`search-index.json` 只索引已发布文章、作品与真实独立文档，查询在本地完成，索引失败提供重试和正常导航入口。

作品标签按方向键、Home、End 切换，展示区高度固定，不自动轮播。列表筛选使用真实分类，将条件保存在 URL。首页滚动内容仅呈现一次；波浪离屏或页面隐藏时暂停。`prefers-reduced-motion` 下关闭持续动画、位移与切换动画。无 JavaScript 时，正文、全部作品链接和原生手机导航仍可用。

代码块保留自动换行和单一复制按钮。复制逐字保留代码内容，成功或失败均有反馈。Mermaid 仅在图表页面加载 11.4.0，保留 strict 安全模式；加载或渲染失败显示源码和说明。

## 2026-10-17 细节优化

波浪由蓝白半透明装饰纹理与轻量 SVG 曲面构成。纹理参考已批准的第二版首屏，使用内置 ImageGen 生成，保存为 `static/images/hero-waves-v2.webp`；它不代表真实项目截图。纹理保留透明度，以两层不同节奏的小幅形变和柔和光影表现流动。SVG 的四条曲面会改变自身曲线，桌面更新上限约 30 次/秒，手机或粗指针设备上限约 16 次/秒并隐藏细丝与第二纹理层。这里的上限不是设备实际帧率承诺。

`assets/js/waves.js` 负责曲面更新，不使用 WebGL、粒子依赖、鼠标跟随或滚动劫持；离屏、页面隐藏和减少动态效果时停止更新。无脚本时显示静态曲面和纹理。

作品面板改为 320ms 入场与 200ms 退出的交叉淡入，支持快速连续切换；标签下划线随选择移动。退出面板在过渡期间设为 inert 和 aria-hidden，避免键盘进入旧内容。手机菜单增加 240ms 展开、160ms 收起，Esc 恢复焦点。减少动态效果时即时切换。卡片仅在精确指针的悬停设备上抬升，触屏与键盘均有独立反馈。

本机浏览器检查不能代替 Android 真机帧率、电量、GPU 内存或线上 Core Web Vitals。录屏用于展示实际渲染行为，截图仅用于检查静态排版。localhost 预览仅电脑本机可访问，Android 端通过 Library 查看录屏和截图。

## 2026-10-17 工作室视觉与跨页升级

保留已批准的蓝色波浪、居中首屏、一大两小作品布局和暖白排版。本轮将作品展示细化为界面侧栏、原文、译文或代码结构的分层组装，并添加可复看的短演示与静态流程说明。ESP32 的流程表示学习方向，不能理解为已经完成设备连接或实测。所有流程在无脚本和减少动态效果时保持完整静态呈现。

`assembly.js` 只对插画内部元素运行一次短 Web Animations 演示，桌面最长约 800ms，手机简化到约 620ms；重看和切换会取消先前的演示。正文、标题、文章列表不再等待滚动淡入。没有滚动吸附、固定滚动段落、模拟在线光标或新增动画依赖。

关于区的 `site/desk.html` 是原创 SVG 桌面意象，电脑、笔记、植物、窗景分层呈现，直接融入纸色背景。它不描述真实住所、设备或个人照片。页脚使用静态的柔和地平线与小植物，所有页面共用。

跨页采用浏览器原生 MPA View Transitions。`navigation.js` 在 `pageswap` / `pagereveal` 阶段为作品表面临时命名，捕获完成后清理，避免 BFCache 返回时名称冲突。普通导航约 160–180ms，作品表面约 420ms。没有 AJAX 路由、链接拦截或 History 导航代理，所以搜索、代码复制和 Mermaid 仍按每次真实文档加载初始化。无 API 支持时为正常页面导航；减少动态效果时关闭跨页转场。

参考观察：实际打开了 [Delineate 首页](https://delineate.appautomaton.com/) 与 [Assembly](https://delineate.appautomaton.com/assembly/)，看到了植物边缘渐隐与多光标、辅助线式构建，也观察到快滚后的未绘制空白。吸收分层构建和背景衔接的设计思想，不复用该仓库代码、SVG 或 skill，不安装其 hooks。原生跨文档 API 依据 [MDN](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API/Using)。Motion 文档仅作节奏参考，无 Motion、React Bits、Magic UI、GSAP 或 Swup 运行依赖。Codrops 的 OnScrollViewSwitch 在本机遇到验证页，不把未看到的动效写成观察结论。

本轮开始前完整保存了现有源文件哈希与可编辑文件副本，位于任务目录的 `upgrade-baseline/`。相对本轮基线的变化记录在 `upgrade-change-manifest.json`。此前未提交的内容保留，不执行 commit、push 或部署。

本轮验证：生产构建与 `npm run verify` 通过；1440、768、390、320px × 深浅色 × 正常/减少动态效果共 16 组、224 次页面布局检查通过。实际 Chromium 中验证连续切换、快速滚动、转场中返回、前进、刷新、原生滚动恢复、Ctrl 新标签页、锚点、下载、外链、搜索、分类与逐字代码复制。手机尺寸额外检查了深色下正常/减少动态效果的转场返回与导航，无 JavaScript 的菜单和真实内容仍可用。演示提示行固定高度，避免控件启用或降级引发布局变化。截图与录屏是浏览器实际输出；手机尺寸为 Chromium 模拟，不代表 Android 真机，也未实测 Safari/Firefox 或线上指标。

## 2026-10-17 项目流程与阅读细节

本轮保留原布局，重点将通用分层入场细化为三种不同的有限流程：VanishTrans 划词高亮、快捷键提示、翻译浮层；ESP32 沿线路经过的信号与亮起的概念显示端；ai-chat 命令行输入、单次请求提示与整条示例响应。项目流程约 1.6–2 秒，手机压缩到约 82%；只演示一次，支持重看、切换取消、离屏取消、页面隐藏取消和减少动态效果即时静止。全部文本在 HTML 中，动画不调用 API，也不伪造运行结果。ai-chat 不模拟未经核实的流式输出；ESP32 显示端明确为概念，未接入设备。

背景、主视觉和标题分别参与共享转场。支持嵌套组的浏览器将主视觉约束在变化中的卡片边界里；不支持时保留完整卡片过渡。实际 Chromium 检查发现历史返回的滚动恢复可能晚于快照，因此按原 Navigation history entry 临时记录来源卡片/页签与坐标，返回时在快照前同步对齐。没有等待导航，也没有改为手动 History 滚动恢复。无法保存来源状态时取消这次复杂反向转场，直接交给浏览器导航。减少动态效果仍保存可用的来源页签状态。

波浪复用原 SVG 与两层纹理，远近层速度和光影起点不同；精确鼠标支持至多 7px / 4px 的平滑视差和归位，触控不追踪。导航下划线连续移动，标签加入滑动底色；菜单关闭缩短至 120ms。文章目录使用 280ms 展开、160ms 收起，支持快速反复切换、Esc、焦点恢复和点选锚点后立即收起。正文不等待动画显示。

保留代码默认自动换行和单一复制按钮；复制反馈放在代码容器内，不推挤文章，重复复制会更新反馈计时，失败显示真实说明并恢复复制图标。中文长标题、正文宽度和锚点留白统一检查。移除了三份未使用的 Doks Jost 字体预载，继续使用系统字体栈；本轮没有增加图片或动画依赖。VanishTrans 仅找到 `docs/archive/visuals/` 的归档视觉参考，未将其当作实测产品截图，也未启动项目补拍。

本轮基线与变化清单位于任务目录的 `flow-baseline/`、`flow-change-manifest.json`；实际浏览器验证结果在 `flow-evidence/`。用户随后明确取消录屏交付，本轮没有录屏或上传 Library，直接通过电脑 `http://localhost:1420/` 检查。手机尺寸验证仍为 Chromium 模拟，不能当作 Android 真机或线上性能结果。

## 2026-10-17 可逆的首屏滚动衔接

`hero-scroll.js` 将当前滚动位置连续映射到标题、说明/按钮、展示区的透明度和小幅位移。标题先退场，展示区在主视觉移到视口上方后才逐渐退出；作品区在进入主要阅读区域前完成渐入。波浪有独立父层，随作品区进入渐渐融入当前纸色背景，深色模式沿用自己的背景颜色。各段时间重叠，向上滚动按相同进度自然恢复，不使用一次性触发代替连续映射。

页面仍按原有文档流滚动，没有固定首屏、额外滚动占位、吸附或延迟导航。尺寸只在初始化、ResizeObserver、视口变化和字体就绪时测量；滚动采用 passive 事件并合并到 requestAnimationFrame，无滚动时不运行持续更新。外层的 CSS `translate` 与原有入场 `transform`、波浪视差、项目流程分离，避免覆盖同一属性。

低于透明阈值的退场区域设置 inert 并禁用鼠标命中；键盘可见焦点所在区域保持完整可见。鼠标点过页签不会让展示窗一直保持不透明。减少动态效果会清除滚动样式和 inert；无 JS 时全部直接显示。跨页返回在对齐原滚动位置后同步更新进度，刷新在页面中段也按当前实际位置初始化。手机降低位移和作品区初始淡化幅度。

本轮备份在 `scroll-baseline/`，变化清单为 `scroll-change-manifest.json`，内部验证数据在 `scroll-evidence/`。按用户要求，不录屏、不上传或交付截图。实际 Chromium 检查包含 1440、390、320px，深浅色、正常/减少动态效果、下滚/回滚/快速跳转、中段刷新、焦点、无 JS 和从详情返回；手机仍为尺寸模拟，非真机。


## 2026-10-17 首次滚动入场

本轮按用户新批准的节奏，覆盖上一节中“作品区可逆渐入”的描述：首屏标题、说明和展示区仍随滚动退场，波浪仍随下方区域进入融入背景；`selected-work` 整区不再设置透明度和位移。下方改为原生 IntersectionObserver + Web Animations 的首次入场，不引入依赖。作品标题/三张卡片、近期文章标题/三行文章、关于标题/正文组/桌面意象，共 11 个独立目标分为 3 组。

标题由 opacity 0、translateY 20px 入场；卡片、文章行和内容组由 opacity 0、translateY 30px 入场。统一 600ms、cubic-bezier(.44,0,.56,1)，视口阈值 0，同一批进入视口的同组项目依次延迟 100ms，延迟上限 200ms，不跨整页累加。进入后 unobserve，停滚继续播放、回滚不重播，新文档加载重新开始。独立 CSS translate 不覆盖卡片 hover transform，也不取消作品内部动画。

默认 HTML/CSS 完整可读。首页头部仅在支持相关能力且没有减少动态偏好时启用短暂防闪烁标记，主脚本未成功接管会在 1.2 秒后全部释放；初始化和回调错误也释放内容。减少动态效果、能力缺失、键盘聚焦均直接展示。中段刷新和浏览器返回会立即显示当前视口及其上方目标，未来内容仍可首次入场；快速跳过的内容不会留在透明状态。沿用原生滚动恢复与现有共享转场对齐事件，不新增路由拦截或 History 写入。

本机生产 HTML 的实际浏览器检查已覆盖首次下拉、停止滚动继续播放、回滚不重播、顶部刷新重置、中段刷新、详情返回、快滚、键盘聚焦，以及 390/320px 的深浅色和横向溢出。另用隔离的生产 HTML 测试页检查无脚本、主脚本缺失的 1.2 秒兜底和减少动态效果的 JS 分支；当前 CUA 浏览器未提供系统媒体偏好切换能力，未声称已模拟操作系统级 prefers-reduced-motion。减少动态效果 CSS 保留强制静态覆盖。手机仍为视口模拟，非真机。

本轮原文件备份为任务目录的 `entrance-baseline/`，变化清单为 `entrance-change-manifest.json`。未录屏、未保存截图交付、未推送或部署。生产预览为电脑本机 `http://localhost:1420/`。
