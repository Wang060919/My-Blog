## 从软件走向设备

ESP32 Lab 是这里对硬件学习方向的整理入口。当前可核实的资料来自小智 ESP32 开源项目，用来理解设备、语音交互与模型服务之间的连接方式。

## 资料来自哪里

学习资料对应[小智 ESP32 上游仓库](https://github.com/78/xiaozhi-esp32)。这是社区开源项目，不把上游实现列为我的原创成果。板卡支持、固件要求与使用方式，应以该项目的正式说明为准。

## 当前进展与边界

目前仅确认已有项目源码与学习资料。还没有足够的个人实测记录证明完成了编译、烧录、屏幕测试或语音对话，因此本页不把这些环节标为已完成。

后续如果形成可复核的实验记录，再补充具体板卡、连接关系、测试条件与结果。页面上的开发板是抽象示意，不是设备实拍。
