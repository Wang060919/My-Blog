在逛 NodeSeek、LINUX DO 等技术论坛时，常会看到“MJJ”、“母鸡/小鸡”、“传家宝”、“CN2 GIA”等让人摸不着头脑的词汇。这些黑话有些是为了避开敏感词过滤，有些则是圈内玩家自嘲、戏谑或对特定商家、线路的形象代称。

本文将这些黑话与核心技术术语进行了系统整理，方便新人查阅与自测。

## 一、 🐣 基础术语与“养鸡场”生态

| 黑话 | 实际含义 | 详细释义 |
| :--- | :--- | :--- |
| **小鸡** | VPS (虚拟服务器) | 指从物理独立服务器上虚拟出来的单个云服务器。 |
| **母鸡** | 独立服务器 (独服) | 宿主机/物理服务器。因为小鸡都是从这里虚拟出来的，故称“母鸡”。 |
| **杜甫 / 毒妇** | 独立服务器 (独服) | “独服”（Dedicated Server）的拼音输入法谐音。 |
| **MJJ** | 广大玩家 / 站长 | “买鸡鸡的人”首字母缩写，圈内网友的自嘲互称，带有戏谑意味。 |
| **超兽 (超售)** | 资源超额售卖 | 商家把母鸡的硬件（CPU/内存/带宽）虚拟出远超物理承载量的小鸡。例如 16G 内存开出 30 台 1G 小鸡。 |
| **大盘鸡** | 大存储 VPS | 硬盘空间极大的服务器（通常 250GB 到数 TB），适合做私有网盘、下载机或流媒体库。 |
| **NAT 鸡** | 共享 IP 的 VPS | 没有独立公网 IPv4，多个用户共享同一个公网 IP，通过映射不同端口来对外提供服务，价格通常极其低廉。 |
| **中转机** | 流量中继服务器 | 位于用户与目标服务器之间的桥梁。通常选国内沿海或线路极佳的 VPS，用来转发流量以降低延迟和丢包。 |
| **落地机** | 出口服务器 (Exit Node) | 实际访问目标网站/流媒体服务的最终节点。通常网络线路一般，但 IP 干净、风控低、能完美解锁 Netflix/Disney+。 |
| **传家宝** | 绝版高性价比套餐 | 性能好、线路极佳、价格极低且**商家已永久下架**的套餐。二手转让时往往有很高溢价。 |
| **灵车** | 随时跑路的服务商 | 价格低到离谱、没有信誉背书或新开的小商家（OneMan）。随时面临倒闭、删鸡、不退款的风险。 |
| **石头盘 / 钻石盘** | 超慢的硬盘 IO | 形容超售极其严重导致磁盘读写极慢：**石头盘** IO 约 30~100MB/s；**钻石盘** 更硬，IO 低于 30MB/s 甚至只有几 MB/s。 |
| **DD (DD系统)** | 纯净重装操作系统 | 利用 Linux 原生的底层命令 `dd`，绕过云厂商自带的镜像系统，直接刷入纯净版官方 Windows/Linux。 |
| **吃灰** | 闲置不用 | 买了服务器后没有实际业务跑，放着白扣月租的常态。 |
| **背刺** | 刚买就降价 | 刚原价购入某款 VPS，商家后脚就发布了更高配置、更低价格的促销款。 |

## 二、 🌐 线路、路由与网络专区（硬核技术）

网络质量是决定一台海外小鸡价值的核心因素，以下是国内三大运营商及海外核心线路划分：

### 1. 中国电信线路
*   **163 骨干网 (AS4134)：** 最传统的普通民用骨干网，节点以 `202.97.*` 开头。晚高峰（19:00~24:00）拥堵严重，丢包率极高。
*   **CN2 GT (Global Transit)：** 电信半程优化线路。去程走普通 163 骨干，回程走 CN2 优化节点，性价比适中。
*   **CN2 GIA (Global Internet Access - AS4809)：** 电信最高级别的企业级精品网，全程双向均走 `59.43.*` 高速节点。即使晚高峰也极稳、低延迟、超低丢包，价格昂贵，被誉为“土豪专属”。

### 2. 中国联通线路
*   **169 网 (AS4837)：** 联通普通民用骨干网。容量大、负载相对较低，直连海外性价比非常高，是近两年的热门平民选择。
*   **A 网 / 9929 (AS9929 / AS10099)：** 原中国网通骨干网，后成为联通产业互联网精品网。稳定性和抗拥堵能力媲美电信 CN2 GIA，晚高峰依然坚挺。

### 3. 中国移动线路
*   **CMI (China Mobile International)：** 移动国际精品线路。移动用户访问香港/东南亚等节点时速度极快，在亚太地区的直连体验极佳（俗称“移动拉一切”）。

### 4. 常见亚太线路
*   **软银 (SoftBank - BBTEC)：** 日本知名运营商线路，联通/移动用户直连延迟极低、带宽大；但遭遇攻击时容易发生路由绕路。
*   **IIJ (Internet Initiative Japan)：** 日本老牌机房网络，电信、联通跑东京/大阪延迟较低，但晚高峰时稳定性弱于软银。
*   **NTT：** 覆盖最广的国际廉价线路，国内直连晚高峰丢包非常严重。

## 三、 🏢 服务商黑话与外号大全

### 1. 云计算大厂
*   **乌龟壳 / 龟壳 / 王八 (甲骨文云 - Oracle Cloud)：** 
    因 Logo 酷似龟壳且防刷风控极其严格（壳硬）得名。因其提供 **永久免费（Always Free）最高 4核24G ARM** 豪华配置，成为广大 MJJ 终极白嫖目标。
*   **CF (Cloudflare)：** 全球最大的免费 CDN/网络防护服务商，免费提供防护、WAF、Workers 等强大功能，被誉为“赛博菩萨”。
*   **CFT (AWS CloudFront)：** 亚马逊旗下 CDN。每月提供 1TB 免费出站流量，但超出后计费极其昂贵（俗称“超额一晚一套房”）。
*   **套路云 (阿里云)：** 因促销优惠规则复杂、续费价格暴涨、各种限制规则多而得名。
*   **良心云 / 凉心云 (腾讯云)：** 早期经常赠送大额无门槛代金券被称为“良心云”；后来严查代理跳板并频繁封禁违规账号，被戏称为“凉心云”。

### 2. 知名 VPS 商家
*   **搬瓦工 (BandwagonHost)：** 早期靠 3.99/4.99 刀年付廉价小鸡成名，后转型做高端 CN2 GIA 线路，价格昂贵但网络极稳。
*   **斯巴达 (SpartanHost / 斯巴拉)：** 主打美国西雅图 Cera 机房的高防 VPS（4837 优化线路），硬件强、抗打能力好，曾一度是抢手的传家宝。
*   **微基主机 (Wikihost / 鸡总)：** 国人老牌主机商，因老板网名带有“屌鸡”且主营服务器业务，被圈内称为“鸡总”。
*   **绿云 (GreenCloud / 宝强云 / 贾乃亮云)：** 因英文名含“Green”被 MJJ 调侃冠名，常在大促时推出大内存、高配置大盘鸡。
*   **五折云 (V.PS)：** xTom 旗下 VPS 品牌，常年搞年付/多周期“五折”优惠促销。

### 3. 低价“四大金刚”（高争议/廉价车）
*   **CC (CloudCone)：** 洛杉矶 MC 机房，价格便宜，支持按小时计费，晚高峰网络有波动。
*   **RN (RackNerd)：** 廉价 VPS 代表，节日促销（黑五、新年）经常出现十几美元年付的便宜机，工单客服响应很快。
*   **VIR (VirMach)：** 老牌低价王者，老板被 MJJ 称为“瘦猴/麻杆”。以极其便宜但**动辄删号封机、不退款、风控极严**闻名。
*   **PR (PacificRack)：** 早期由 QuadraNet 成立的低价品牌，因持续宕机、辱骂客户、删库删号，最终已彻底破产倒闭。

### 4. 经典远古传家宝
*   **三毛 / 五毛 (RUVDS)：** 俄罗斯机房超低价 VPS，因早年年付仅需 30 卢布（约合人民币 2.7 元）得名。
*   **3O / 5O (Online.net / OneProvider)：** 早期欧洲机房推出的 3 欧元 / 5 欧元月付低价独立服务器。
*   **老伯力 / 新伯力：** Gcore 旗下俄罗斯新西伯利亚机房，早年直连中国延迟极低（低至 50ms 左右），后因线路调整而落幕。

## 四、 🛠 常用缩写、工具与生态黑话

### 1. 行业缩写速查
*   **玉米：** 域名（Domain）。
*   **北岸：** 备案（ICP 备案的谐音避审词）。
*   **白女票：** 白嫖（免费获取服务）。
*   **OneMan：** 只有一个人运营的微型 IDC 商家，抗风险能力弱，跑路风险高。
*   **Aff / Affman：** Affiliate（推广返利链接）。分享带 Aff 的链接可在他人下单后赚取佣金，专发 Aff 的人被称为 Affman。
*   **PT / 盒子 (Seedbox)：** 私有 BT 下载体系（Private Tracker）。用于挂机保种、大流量上下行的服务器被称为“盒子”（如 Hetzner、Netcup 的大盘鸡）。
*   **探针：** 装在小鸡上的状态监控网页程序（如 ServerStatus、Nezha 等），用于实时展示服务器在线率和性能。

### 2. 账号与服务缩写
*   **AZ：** Microsoft Azure（微软云）。
*   **OD：** Microsoft OneDrive 云存储。
*   **A1 / A1P：** 微软 Office 365 针对教育机构推出的免费/特权订阅版本。
*   **TG：** Telegram 即时通讯软件。
*   **GV：** Google Voice（谷歌虚拟美国电话卡）。
*   **PP：** PayPal 国际支付工具。
*   **NF / 奈飞：** Netflix 流媒体视频平台。

### 3. 常见网络工具谐音
*   **酸酸 (SS)：** Shadowsocks。
*   **酸酸乳 (SSR)：** ShadowsocksR。
*   **V2：** V2Ray。
*   **HY (歇斯底里)：** Hysteria，基于定制 QUIC 协议的双边加速网络工具，专为恶劣、高丢包网络环境优化。

## 五、 ⚠️ 圈内江湖黑话与安全术语

*   **DMCA：** 《美国数字千年版权法案》。机房收到版权方（如盗版电影、侵权源码）投诉后会下发 DMCA 警告，不及时处理会被强行清退并删机。
*   **127 (127.0.0.1)：** 本机回环地址。指域名被 DNS 污染解析到了本地，或机房遭遇攻击后直接将你的 IP 路由黑洞化（封入小黑屋），导致网站全网瘫痪打不开。
*   **剑皇（鉴黄）：** 
    原指利用大流量脚本持续抓取并刷爆涉黄、盗版站点的 CDN/对象存储（如阿里云 OSS 流量费），导致违法站点站长产生数万乃至数十万元巨额欠费而被迫关站的民间网络攻击行动。
*   **晚高峰：** 
    北京时间每日 19:00 至 24:00。此时国内国际出口交换机负荷达到峰值，无优化线路的海外连接会出现严重的延迟飙升与丢包。
